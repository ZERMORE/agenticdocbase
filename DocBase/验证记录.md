## 实际 doc2md → DocBase 工作流

实际输入为现有 `doc2md/output/smoke` 中成功解析的 sample.pdf 产物：1 份文档、7 个块，原图占位不作正文索引，标题用作上下文，最终生成 5 个检索片。

实际执行：

```bat
run.cmd scan --input "..\doc2md\output\smoke"
run.cmd build --profile bm25-only
run.cmd query --profile bm25-only --question "1729" --top-k 3
run.cmd test --profile bm25-only --dataset ".\eval\smoke.jsonl" --top-k 5
```

结果：

- scan：发现并启用 1 份有效文档，无冲突和拒绝项。
- build：成功，5 个检索片，model requests=0。
- 查询 1729：命中表格及正文，来源指向复制的 sample.pdf，第 1 页。
- 查询 INPUT OUTPUT TRANSFER：命中图片释义，保留对应图片和来源位置。
- 题集为 2 道可回答题、1 道无答案题；2 道可回答题 Hit@5、Recall@5、MRR@5 均为 1.0，无答案题返回零命中。
- 上述指标仅表示已知微型样例的链路成功，不代表真实技术文档上的总体准确率，也不代表 Agent 回答/拒答能力。

构建/查询/评测结果位于 storage/reports；CURRENT 指向本次成功建立的 BM25 快照。失败的混合模型调用没有替换该快照。
