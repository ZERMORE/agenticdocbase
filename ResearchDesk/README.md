# 研知工作台使用指南

研知在 Windows 上提供文献管理、限定范围检索、带引用问答及研究记录管理。从仓库根目录安装与启动，见 [快速开始](../README.md#安装与启动)。

## 知识库与检索

- 新建知识库后可上传 PDF、DOCX、PPTX、旧 DOC/PPT、PNG 和 JPEG，每文件不超过 100 MB，每批最多 20 个。
- 选择「仅离线文本解析」可在未配置模型时入库。扫描件识别和旧 Office 文件转换取决于解析依赖。旧 Office 需要 LibreOffice，部分 OCR 或视觉任务需要额外工具或模型。详见 [doc2md](../doc2md/README.md)。
- 上传后由 Worker 解析并发布索引。在「任务中心」查看进度和错误，等文档显示「可检索」再做内容搜索。
- 按作者、年份、标签或选定文档限定问答范围。文档移出后会从新检索范围排除，可从「已移出」恢复。历史引用依赖来源快照。
- 可预览原文、Markdown 和图像，查看解析质量，纠错或对指定内容重新解析。

## Zotero 与目录监控

在知识库底部添加 Zotero 同步来源，填写**带附件路径的 Zotero 导出 JSON**和本机 `storage` 目录。JSON 中条目需包含 `attachments`，PDF 附件路径可放在 `path` 或 `localPath`。先用小分类预览，确认附件能找到再应用。CSL JSON 通常只有引文元数据，需换成含附件路径的导出。

Zotero 自动同步检查你提供的导出文件，更新分类后需重新导出到同一路径。另一种方式是在设置的「后台与备份」登记普通目录，按文件变更增量导入。源附件由工作台只读访问，缺失或离线时保留已导入资料。

## 问答、引用与历史

1. 在「个性化设置 → 模型配置」填写所需角色的 HTTPS 接口地址、模型和 Key。网页凭据由 Windows DPAPI 加密，配置版本在任务提交时确定。
2. 为目标知识库开启「允许外部模型处理」。问答时问题和选中的证据会发送给所选模型服务。合成连接测试会向供应商发送少量测试数据。
3. 在聊天中选库和资料范围。可配置流式草稿，最终回答经过引用校验后提交。点击引用打开引句和 PDF 位置，拖动面板左缘可调整宽度。
4. 在回答偏好中选择支持性检查强度。引用原文匹配和结论支持性是两项检查，阅读全文时仍需核对结论。
5. 从对话末尾创建分支，或编辑旧问题、重新生成以从更早位置分叉。收藏回答和引句，导出 Markdown/JSON，或在侧栏归档和恢复。永久删除需要确认。

独立 CLI 读取各组件自己的 `.env`。服务首次创建配置时可从这些文件初始化，此后请在设置页更新网页模型。

## 日常维护

| 位置 | 内容 |
| --- | --- |
| `ResearchDesk/data/app.sqlite` | 知识库、会话、任务、设置和来源登记 |
| `ResearchDesk/data/uploads/`、`parsed/`、`runs/` | 托管文档、解析结果和任务记录 |
| `ResearchDesk/data/logs/` | API 与 Worker 日志 |
| `DocBase/storage/` | 索引版本及不可变来源快照 |

在任务中心可停止任务。解析、建库等后台任务可手动重试，问答请在会话中重新发送。关闭网页后，后台会继续运行。使用根目录的 `stop.cmd` 停止。

## 备份与恢复

在项目根目录运行 `backup.cmd`，在输出目录查看 SQLite 快照、文件包和校验清单。备份可包含 DPAPI 加密凭据，跨 Windows 用户恢复后可能需要重新填写 Key。

停止工作台后，将备份恢复到一个**尚不存在的目录**。以下命令在项目根目录的命令提示符运行，按实际路径替换引号中的参数：

```bat
ResearchDesk\service\.conda\python.exe -X utf8 -m researchdesk restore --backup-path "D:\Backups\研知备份" --destination "D:\研知恢复数据"
set "RESEARCHDESK_DATA=D:\研知恢复数据"
start.cmd
```

恢复后先检查库与引用，并按需重新启用目录监控和 Zotero 同步。要返回默认数据目录，停止服务并在同一终端清除 `RESEARCHDESK_DATA`。

## 验证与故障排查

- `setup.cmd` 提示找不到 Conda 时，打开 Anaconda Prompt 重试。Node 版本过低时更新到 22.12 或更新版本。
- 页面打不开时先运行 `status.cmd`，再查 `data/logs`。浏览器应访问 `127.0.0.1:8765`。
- 资料未出现在检索中时，检查解析质量、索引任务和当前限定范围。
- 模型请求失败时，查看对应任务诊断，检查接口、模型权限及账户额度。
- 开发回归使用仓库根目录的 `verify.cmd`。浏览器合成测试可用 `web/e2e-v2-fixture.py` 与 `web/e2e-v2.mjs`。
